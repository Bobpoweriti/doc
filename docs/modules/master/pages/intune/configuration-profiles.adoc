== Contexte et objectifs

Ce document décrit l'ensemble des politiques de configuration Intune déployées sur les tenants Microsoft 365 gérés par POWERiti dans le cadre de l'offre mySerenity.

Ces politiques constituent le socle commun appliqué de façon standardisée à l'ensemble du parc client. Elles visent à :

* Chiffrer automatiquement tous les disques (BitLocker)
* Durcir le navigateur Edge et désactiver le gestionnaire de mots de passe natif
* Créer et maintenir un compte administrateur local standardisé (PowerAdmin)
* Gérer automatiquement l'espace disque des postes
* Assurer la rotation automatique du mot de passe administrateur local (LAPS)

== Détail des politiques

[#pol-bitlocker]
=== Bitlocker - ON

*Description* +
Chiffrement automatique et silencieux de tous les disques.

*Paramètres appliqués*

[cols="3,2"]
|===
|Paramètre |Valeur

|Exiger le chiffrement des appareils
|Activé

|Lecteurs système — Chiffrement forcé
|Enabled

|Type de chiffrement
|Full encryption

|PIN au démarrage
|Désactivé

|Avertissement autre chiffrement
|Désactivé

|Chiffrement utilisateur standard
|Désactivé
|===

NOTE: Le PIN est délibérément désactivé pour éviter les blocages lors des interventions à distance.

---

Durcissement du navigateur Edge et désactivation du gestionnaire de mots de passe natif (Keeper utilisé à la place).

*Paramètres appliqués*

[cols="3,2"]
|===
|Paramètre |Valeur

|Désactivé

|Expérience zone de recherche nouvel onglet
|Activé

|Limiter longueur mots de passe (Gestionnaire Edge)
|Désactivé

|Extensions mode silencieux
|Activé

|Domaines gestionnaire de mots de passe Edge
|Désactivé

|Moteur de recherche par défaut
|Activé

|Déclencheur avertissement mot de passe
|Désactivé

|Installation extensions spécifiques
|Activé

|Suppression mots de passe Edge
|Désactivé

|Suppression données navigation à la fermeture
|Désactivé

|Enregistrement cookies à la fermeture
|Désactivé

|Enregistrement mots de passe (Gestionnaire Edge)
|Désactivé

|Configurer les cookies
|Activé

|Suggestion mot de passe fort
|Désactivé
|===

IMPORTANT: Le gestionnaire de mots de passe Edge est entièrement désactivé. Keeper est le seul gestionnaire autorisé sur les postes mySerenity.

[#pol-poweradmin]
=== Configuration PowerAdmin

*Description* +
Crée un compte administrateur local standardisé `PowerAdmin` sur tous les postes via OMA-URI.

*Paramètres appliqués*

[cols="2,1,3"]
|===
|Paramètre |Type |OMA-URI

|Add AdminPower to Local Administrators
|Entier
|`./Device/Vendor/MSFT/Accounts/Users/PowerAdmin/LocalUs...`

|Create PowerAdmin password
|Chaîne
|`./Device/Vendor/MSFT/Accounts/Users/PowerAdmin/Passwo...`
|===

NOTE: Cette policy fonctionne en trio avec `Enable LAPS` et `LAPS` pour assurer la création, l'activation et la rotation du compte `PowerAdmin`.

[#pol-laps]
=== LAPS

*Description* +
Rotation automatique du mot de passe du compte `PowerAdmin`, stocké dans Entra ID.

*Paramètres appliqués*

[cols="3,2"]
|===
|Paramètre |Valeur

|Répertoire de sauvegarde
|Microsoft Entra ID uniquement

|Rotation du mot de passe
|7 jours

|Nom du compte géré
|`PowerAdmin`

|Complexité
|Majuscules + minuscules + chiffres + caractères spéciaux

|Longueur
|20 caractères

|Action post-authentification
|Réinitialiser à l'expiration de la période de grâce

|Délai après réinitialisation
|24 heures
|===

TIP: Le mot de passe est consultable depuis le portail Intune par les admins POWERiti : *Appareils > [nom du poste] > Mot de passe administrateur local*.

WARNING: L'accès au mot de passe LAPS est réservé aux admins POWERiti. Ne jamais communiquer ce mot de passe au client.

---

== Notes de gestion

IMPORTANT: Ces politiques sont communes aux 3 tenants mySerenity. Toute modification doit être validée par le Directeur Technique avant déploiement.

NOTE: La politique `Configuration PowerAdmin` nécessite que `Enable LAPS` soit déployée en amont sur le poste pour fonctionner correctement.

WARNING: La désactivation de BitLocker sur un poste nécessite une procédure documentée et une validation formelle. Ne jamais désactiver sans ticket Autotask approuvé.
