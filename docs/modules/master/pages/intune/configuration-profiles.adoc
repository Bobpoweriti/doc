== Notes de gestion

IMPORTANT: Ces politiques sont communes à tous les tenants mySerenity. Toute modification doit être validée par le Directeur Technique avant déploiement.

NOTE: La politique `PowerAdmin` nécessite que `Enable LAPS` soit déployée en amont pour fonctionner correctement.

WARNING: La désactivation de BitLocker nécessite une procédure documentée et un ticket Autotask approuvé.
