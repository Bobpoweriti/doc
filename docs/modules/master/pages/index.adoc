= Tenant MASTER — Documentation de référence
POWERiti — Équipe Technique
:version: 1.0

Le tenant *MASTER* est le tenant Microsoft 365 de référence POWERiti.
Il sert de template de déploiement pour l'ensemble des environnements clients.

Toute politique, configuration ou règle validée ici est considérée
comme standard de déploiement POWERiti.
