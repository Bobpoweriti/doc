== Notes de gestion

IMPORTANT: Les emplacements nommés (`GEO_FRANCE`, `GEO_TEMPO-COUNTRY-ALLOWED`, `IP_COREVIEW`) doivent être maintenus à jour dans *Microsoft Entra ID > Conditional Access > Named Locations*.

WARNING: Les groupes `GRP_ADMINISTRATEUR` et `GRP_HORS-FRANCE-OK` sont des pivots d'exception — leur composition doit faire l'objet d'une revue régulière.

NOTE: Toute demande d'exception doit être instruite en ticket Autotask et validée par le Directeur Technique.
